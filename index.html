Perguntas frequentes

Respostas rápidas. Para falar com uma pessoa, use qualquer botão de atendimento acima.

📷 Minha câmera está sem imagem. O que faço?

Confira se o equipamento está ligado e se os cabos estão firmes. Veja se o problema acontece em uma câmera ou em todas. Não abra fontes nem equipamentos energizados. Se persistir, chame o suporte pelo chat.

📱 Não consigo acessar pelo celular.

Verifique sua conexão e se está usando o aplicativo correto. Não compartilhe senha nem código de acesso pelo chat.

🛡️ Qual é a garantia dos serviços?

As condições informadas pela KS são de 3 meses para novas instalações de sistemas de câmeras e 1 mês para manutenção. A cobertura deve ser confirmada conforme o serviço realizado.

📅 O agendamento é confirmado na hora?

Não. A data e o período são preferências. A equipe confirma a disponibilidade durante o atendimento.

🔒 Privacidade: cada conversa pelo chat tem um link individual. Não compartilhe esse link com outras pessoas. Não envie senhas, códigos de acesso ou dados bancários.
